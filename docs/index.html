Armed Up 'N' Ready

Solo gives you four AI officers, but co-op gives you none. This mod puts them back in co-op and deploys exactly as many as your lobby is missing, for a full five-person squad every mission.

    How it works

    Ready or Not already has almost everything needed. The mod only switches it on.

    1. 01

      The switch

      A hidden console variable, a.RonSpawnSwatInIncompatibleMode, makes co-op spawn the solo squad. It isn't flagged as a cheat, so it works in the retail build.

    2. 02

      The count

      When a match starts, the game respawns every player and then calls SpawnPolice(). The mod counts players while their characters are being built and sets the switch just in time.

    3. 03

      The trim

      SpawnPolice() always spawns four officers. About a second later, the mod removes the extras the same way the game's own debug command does, and corrects the officer counters.

    Install

    About two minutes, and only on the host's PC.

    1. Get UE4SS

      Download the UE4SS_v3.0.1-*.zip from the experimental-latest release and extract it into the game's Win64 folder:

      steamapps\common\Ready Or Not\ReadyOrNot\Binaries\Win64

    2. Drop in the mod

      Extract the latest release zip into the same folder. That creates:

      Win64\ue4ss\Mods\ArmedUpNReady

    3. Host and deploy

      Launch from Steam, host a co-op lobby and start a mission. ue4ss\UE4SS.log should show a line like:

      [ArmedUpNReady] humans=2 bots=3

    Want a smaller squad?

    Change one line at the top of Scripts\main.lua. For example, 4 gives a duo two bots.

    local SQUAD_SIZE = 5 -- players + bots

    FAQ

    Do my friends need the mod?

    No. Only the host runs UE4SS and the mod. Everyone else plays the normal game.

    Can clients command the bots?

    No, only the host. Ready or Not has no network call for a client to give SWAT orders, so client commands would need a much bigger mod on every PC.

    What if someone leaves partway through a mission?

    The squad size is set when the mission starts and stays that way until the next deploy.

    Why do I keep the Blue element first?

    The game puts Alpha and Beta in Blue. Smaller squads keep officers in spawn order.

    Will it survive game updates?

    It relies on game internals, so a large patch can break it. Update UE4SS first, then check for a new release.
